# WhatsChatClone 项目开发进度与架构说明

## 项目概况
WhatsChatClone 是一个基于 Swift 和 SwiftUI 开发的即时通讯应用克隆。项目采用 MVVM 架构，并使用 SwiftData 进行本地数据持久化，致力于还原像素级的交互体验。

## 当前进度 (截至 2026年6月1日)

### 已完成功能
- [x] **导航系统**: `MainTabBarView` 配置及 WhatsApp 经典主题色渲染。
- [x] **聊天详情页核心 UI**: 消息列表渲染、高仿气泡样式及自动滚到底部逻辑。
- [x] **键盘与输入交互**:
    - 统一键盘和附件面板的弹出/收起逻辑。
    - 自动避让键盘，确保聊天内容始终可见（使用 `safeAreaInset`）。
    - 滑动聊天列表自动收起键盘和面板。
- [x] **附件面板集成**: 支持菜单选项交互，集成 `ZLPhotoBrowser` 选择图片并发送。
- [x] **图片消息功能**: 支持发送图片消息及点击放大预览。
- [x] **通话系统 (核心)**:
    - 语音通话和视频通话功能的 UI 与业务逻辑。
    - **悬浮窗管理**: 支持通话最小化为悬浮气泡，且不中断通话状态，支持全屏无缝切换。
- [x] **互动直播系统 (New)**:
    - `LiveRoomView` 沉浸式流媒体播放。
    - 高仿弹幕引擎：支持自动滚动、随机颜色模拟及实时互动。
    - 礼物与点赞特效：集成超级火箭送礼及爱心点赞计数。
- [x] **社群语聊房 (New)**:
    - `CommunityRoomListView` 多人语音房列表。
    - 像素级卡片设计：包含 LIVE 呼吸灯、麦位头像堆叠（Avatar Stack）。
- [x] **系统设置与维护 (New)**:
    - 模块化卡片式布局。
    - **缓存管理**: 接入 `ImageCacheManager` 实现缓存自动计算与一键清理。

### 核心架构与逻辑
- **数据层**: 使用 SwiftData 的 `@Query` 实现消息与通话记录的实时监听。
- **状态管理**: 通过 `OverlayCallManager` 和 `AudioRoomManager` 驱动全局悬浮窗状态机。
- **布局策略**: 深度使用 `safeAreaInset` 管理 UI 避让，结合 `ScrollViewReader` 精准控制动态流（聊天、弹幕）。


## 待办任务

- [ ] **性能优化**: 对于超长消息记录和海量弹幕的懒加载与内存分页优化。
- [ ] **真实对接**: 将当前的模拟直播拉流与弹幕计时器对接至真实生产环境服务器。
- [ ] **国际化**: 支持多语言切换。

---
*注：本项目开发遵循高性能、响应式 UI 开发原则。*
